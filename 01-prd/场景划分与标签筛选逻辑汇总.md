## 五、标签体系说明

### 5.1 标签类型


| 标签类型     | 用途          | 示例                                  |
| -------- | ----------- | ----------------------------------- |
| **内容标签** | 区分视频课程的教学类型 | 概念课、解题课、课文精讲、进阶理解、实验操作 等            |
| **场景标签** | 标记课程适用的学习场景 | 课前预习、课后巩固、单元复习、作业精讲、期中期末重点、新题型、日常积累 |


### 5.2 筛选逻辑规则

1. **组内关系**：同一标签类型内多个标签之间为 **OR**（满足任一即可）
2. **组间关系**：内容标签 与 场景标签 之间为 **AND**（须同时满足）
3. **多条件组合**：当一个场景有多个筛选条件组时，各组之间为 **OR**
4. **隐藏标签**：指定标签在前台界面不展示给用户，但仍参与后端筛选逻辑

### 5.3 "加餐" 场景说明

- "加餐" 场景下的卡片（同步刷题、培优课钩子）不依赖标签筛选，直接按资源类型聚合
- 标记 ~~加餐~~ 表示该场景的内容不通过标签筛选逻辑获取

### 5.4 暂不上线学科

以下学科因当前内容较少，筛选逻辑暂不上线，仅展示预习场景的基础配置：

- 初中历史、道法
- 高中地理、高中历史、高中政治
