## 写在前面：学生日常如何自主学习

帮助梳理思路 + 拉齐认知

总的来说是个 **"预习 → 听课 → 课后复习 → 纠错巩固 → 系统复习 → 考试"** 的闭环。

其中：
- **校内自主学习时间**被高度挤占，呈现碎片化和紧扣进度的特点
- **假期**是学生"弯道超车"或"查漏补缺"的黄金期，学习环节和平日类似，但界限较为模糊

> 注：以下列出的是理想化流程（毕竟相当一部分学生连作业都不做）

---

## 日常阶段

### 听课
在学校正常上课。

### 课后复习

#### 知识点梳理
学习习惯好的学生，会通过 **过教材 / 过教辅 / 过笔记** 的方式完成，顺序可能在做作业之前，也可能会在做作业之后。

#### 做作业
这是自主学习最主要（完成人数最多）的一步，用途主要是消化当天知识，检测当天的听课效果。

#### 定向加餐
完成校内作业后，有的学生会 "加餐" 看教辅、看课或做题，可能是补差也可能是拔高。

### 纠错巩固
学习习惯好的学生，会利用日常中的错误，制作"错题本"，分析考点和错误原因。

### 预习
花一点时间快速翻阅明天的教材，以便第二天课上重点听讲；有的老师也会直接布置预习作业。

> 注：以上为常规的一日学习。周末及日常小考的备考，会更倾向于"复盘"和"拔高"，集中在 定向加餐 / 纠错巩固 这两个环节。

---

## 毕业备考

### 系统复习

#### 地毯式复习（一轮复习）
回归课本、整理笔记，梳理知识网络

#### 专项突破（二轮复习）
专项刷题，攻克错题本

#### 实战演练（做真题）
刷真题、套卷，找考试手感

> 注：不是所有的学科学段、所有考试都有清楚的轮次，但哪怕是就用3天复习，这个系统复习流程也是行得通的。

---

## 假期

复习（本质上是做作业+纠错+系统复习）：
1. 快速完成学校布置的寒暑假作业（基础任务）
2. 分析上一学期的学习情况，找出薄弱环节，进行针对性的"补坑"复习

预习（学得好的学生也会加餐做题）：
1. 借阅下学期教材：通读新书
2. 跟课/自学：观看网课或自行研读教辅，提前掌握下学期的核心知识点，并做练习
3. 背诵：提前背诵下学期的古诗词、英语单词等

## 关于"同步刷题"的问题分析

### 现状问题

同步刷题看似应该和同步视频课紧密挨着，但实际**定位很不清楚**：
- **梳理知识点？** 肯定不是
- **做作业？** 它不太能对作业产生直接帮助，更像是"课内作业的延伸"
- **定向加餐** — 更接近这个，主要服务于"能认识到自己的薄弱点就在这个知识目录下"的学生

但现在各学科同步刷题也有点**"垃圾站"倾向**。

### 功能诞生背景（与金老师沟通了解）

| 功能 | 背景说明 |
|------|----------|
| **同步刷题** | 最初是学练刷测诊纠的"测诊纠"；在天梯会用（有二级目标和难度目标等级）；有些学科把这些题放在了视频后的"更多题目"里，但和视频后配题难度脱节，数据不佳；是**素材驱动而非场景驱动** |
| **试卷库** | 作为稀缺资源提供。补充：政策所限未来"联考"会变少，名校试卷更稀缺 |
| **考前突击** | 设想了学生心中"抄作业没有意义"的场景，做法是筛卷子的高频题 |
| **高频错题** | 吸引力低（日均吸引率1.55%，贡献率0.45%） |
| **专项突破** | 日均吸引率2.48%，贡献率0.71% |

### 关于"同步刷题"的共识结论

- **定位**：偏加餐；呈现价值的素材库
- **在学习流程中的位置**：学生自主选择要不要做，和时间不挂钩
- **对标**：类似于学生平时会做的"练习册"

## AI 建议：将同步配题拆解为三种形态

### 核心诊断：为什么现在定位尴尬？

目前的痛点在于将"题目"看作了"视频的附属品"或"作业的竞品"：
- **作为"作业的延伸"**：学生在学校已经很累了，如果只是为了"多做点题"，除非是学霸，否则动力不足
- **作为"自学的专属作业"**：完全脱离学校节奏、只靠APP自学的K12学生极少
- **作为"习题堆放处"**：没有标签，学生面对海量题目会有巨大的认知负担

### 破局思路：将题目拆分为三种功能模块

#### 形态1："随堂检测"（放在视频播放结束后）

| 维度 | 说明 |
|------|------|
| **用户心态** | "我刚看完视频，我真的懂了吗？还是只是'眼睛学会了'？" |
| **功能定位** | 即时反馈与信心确认 |
| **位置** | 紧贴视频，甚至可以是视频内的交互，或者视频下方的"闯关" |
| **题量** | 极少（3-5题） |
| **难度** | 基础偏中，甚至可以直接复用视频里讲过的例题变形 |
| **价值** | 给学生一种"Close the loop"（闭环）的满足感。这不叫刷题，这叫"确认我学会了" |

> 💡 这部分相当于现有的【课后题】（或叫专项题/出门测）

**关于"自动跳转"的问题**：
- 打断了"完课"的奖赏回路：学生看完视频的那一刻，大脑会释放多巴胺，觉得"我学完了一节"。如果立刻弹题，成就感会被瞬间打断
- 剥夺了用户的掌控感：连"看完视频歇一秒"的权利都没有，会本能抗拒
- 可能降低视频完播率：学生知道看完视频会强制跳题，可能提前关掉

**建议交互方案**：
- 方案A：显性化的"两段式"进度条（视频 + 测一测）
- 方案B：视频内的"热点交互"（视频结束后浮出卡片邀请挑战）

#### 形态2："考前抱佛脚"（放在单元/章节层级）

| 维度 | 说明 |
|------|------|
| **用户心态** | "明天要单元测试/期中考试了，这章的重点题型有哪些？我怕考砸。" |
| **功能定位** | 定向复习与查漏补缺 |
| **位置** | 不要放在每节微课后面，而是放在"单元/章"的层级 |
| **形式** | 打包成"重难点题型集萃"或"单元测试卷" |
| **价值** | 解决实际的应试焦虑。这时候学生不仅愿意刷题，而且愿意刷难题 |

**建议命名**：
- "单元必刷题"（强调必要性）
- "考点基本功"（强调地基，与培优区分）
- "考试常考题"/"高频题型库"（强调频率而非难度）
- "易错题避坑"（针对中等生）

**与培优课的区分**：
- 同步课配题 = "防守"（保基础、抓必考、不丢分、跟上学校进度）
- 培优课 = "进攻"（攻难题、学大招、拿高分、超越班级平均）

#### 形态3："搜题式的反向挂载"（放在知识点/错题本层级）

| 维度 | 说明 |
|------|------|
| **用户心态** | "学校作业这道题我不会做，或者这类型的题我老做错。" |
| **功能定位** | 精准打击薄弱点 |
| **逻辑** | 题目不再是视频的下游，而是入口。学生做不出来再推荐看对应的视频 |
| **价值** | 解决学校作业的痛点 |

> 💡 这部分更倾向于"拍学"那一条路径上的内容

## 数据参考（团队讨论记录）

### 场景表现对比

| 场景 | 日均吸引率 | 日均贡献率 | 评价 |
|------|-----------|-----------|------|
| 考前突击 | 8.27% | 6.15% | 场景性明确，表现好 |
| 专项突破 | 2.48% | 0.71% | 表现较差 |
| 高频错题 | 1.55% | 0.45% | 表现较差 |

### 团队洞察

1. **专项突破和高频错题**：是"技术达不到，但识别到用户需求，做了很多妥协后给到的降级/平替版本解决方案"
2. **同步刷题更像一个题库**：给学生提供"洋葱这里有很多题，当我开启题海战术的时候我可以来这里刷题"的安全感
3. **课后题应该更显性**：课后题才是针对同步课视频完成"学练闭环"的动作；同步刷题是另一个学习环节的事情
4. **考前突击场景性非常明确**：比定向刷题类的还明确，更接近于考试前的末尾一环

## 用户确认的关键设计方向

### 入口策略

- **当前阶段**：保留"教材同步"和"同步刷题"两个入口
- **内部呈现**：无论从哪个入口进入，都看到同一个整合后的章节列表页
- **未来验证**：验证有效后再考虑合并入口（或先做实验组验证）

### 章节列表页内部改造方向

按学习场景聚类整合 Tab，例如：
- **适合预习**：预习类视频、背诵类资源
- **适合复习**：复习类视频、课后题、学案
- **适合加餐**：同步刷题、错题本、定向补弱

### 核心目标

1. **贴合用户学习路径**：按场景组织资源，而非按资源类型分流
2. **传递课程价值**：在列表页展示"这门课能帮你什么"和"如何使用"
