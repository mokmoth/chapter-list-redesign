⚡ 三个最容易出错的配置

┌─ 错误1 ─────────────────────────────────────────────────────────────────────────────┐
│ ❌ 错误行为：访问权限选"私有"                                                      │
│ ✅ 正确做法：选"公有读"                                                            │
│ 🎯 后果：如果选错，团队完全无法访问！                                              │
└─────────────────────────────────────────────────────────────────────────────────────┘

┌─ 错误2 ─────────────────────────────────────────────────────────────────────────────┐
│ ❌ 错误行为：错误文档设为空或其他文件                                              │
│ ✅ 正确做法：错误文档必须设为 index.html                                           │
│ 🎯 后果：SPA 路由会 404，比如访问 /login 会无法访问                               │
└─────────────────────────────────────────────────────────────────────────────────────┘

┌─ 错误3 ─────────────────────────────────────────────────────────────────────────────┐
│ ❌ 错误行为：上传文件后没有等待配置同步                                            │
│ ✅ 正确做法：上传后等待 1-2 分钟，让配置生效                                       │
│ 🎯 后果：立即访问可能出现 404，等等就好了                                         │
└─────────────────────────────────────────────────────────────────────────────────────┘

📁 文件上传要求

上传位置：存储桶详情 → 文件列表

要上传的文件（来自 npm run build 的 dist 文件夹）：

✅ 应该看到的文件结构：
   /
   ├── index.html              ⚠️ 必须在根目录！
   ├── assets/
   │   ├── xxx.js
   │   ├── xxx.css
   │   └── ...其他资源
   └── ...其他静态文件

❌ 错误的上传方式：
   • 上传整个 dist 文件夹本身
   • 上传 src 或 node_modules
   • 忘记上传 index.html

🧪 测试访问清单

部署完成后，请依次测试：

□ 直接访问链接
  → 应该看到你的 Vue 原型首页

□ 测试页面交互
  → 所有按钮、表单等功能应该正常工作

□ 刷新页面
  → 应该不会出现 404
  → 这验证了 SPA 路由工作正常

□ 测试子路由
  → 如果你的应用有其他页面（如 /login、/dashboard）
  → 直接访问这些 URL 也应该能打开

□ 用手机访问
  → 应该能正常响应式显示

□ 在不同浏览器测试
  → Chrome、Safari、Firefox 等都应该正常

📞 遇到问题？

如果配置后访问还是有问题，按以下顺序检查：

1️⃣ 检查基础配置
   • 存储桶权限是否是"公有读"？
   • 静态网站托管是否启用了？
   • 错误文档是否是 index.html？

2️⃣ 检查文件上传
   • index.html 是否在根目录？
   • assets 文件夹是否完整？
   • 用"文件列表"验证

3️⃣ 等待配置同步
   • 新配置需要 1-2 分钟生效
   • 等等再试，或清空缓存重试

4️⃣ 检查浏览器缓存
   • Ctrl+Shift+Delete 清空缓存
   • 或用无痕窗口重新访问

5️⃣ 检查 CDN
   • CDN 加速需要 5-10 分钟完全同步
   • 如果还是慢，可能是 CDN 节点延迟

快速查询：为什么我的链接无法访问？

问题                           原因                         解决方案
─────────────────────────────────────────────────────────────────────────────────────
404 错误                       • 文件未上传                 重新上传 dist/ 文件
                              • 配置未生效                 等待 1-2 分钟重试
                              • 错误文档配置错误           检查是否设为 index.html

跨域错误 (CORS)               • CORS 未配置               配置 CORS 规则
                              • CORS 规则不完整           允许所有 HTTP 方法

路由 404                       • 错误文档不是 index.html    修改为 index.html
                              • 这是最常见原因！

访问很慢                       • CDN 未启用                 启用 CDN 加速
                              • CDN 未同步                 等待 5-10 分钟
                              • 浏览器缓存问题             清空缓存重试

权限拒绝                       • 存储桶权限是私有           改为"公有读"
                              • 未配置 CORS               配置 CORS
