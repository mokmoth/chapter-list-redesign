# 快速部署指南：腾讯云静态网站托管

**总耗时：30分钟** | **预算：¥0-50首月** | **难度：⭐⭐**

---

## 前置准备

- [ ] 腾讯云账号（如无请先注册，支持微信/QQ快速登录）
- [ ] 已构建的项目文件（dist文件夹）
- [ ] 浏览器（Chrome/Safari/Edge任意）

---

## 步骤1：开通腾讯云静态网站托管（3分钟）

### 1.1 进入服务

- 登录 [腾讯云控制台](https://console.cloud.tencent.com/)
- 搜索框输入"静态网站托管"
- 点击进入服务

### 1.2 创建网站

1. 点击"新建"或"创建网站"
2. 填写网站信息：
   - **网站名称**：`chapter-list-redesign`（自定义）
   - **选择地域**：建议选择`广州`或`北京`
3. 选择计费模式：**按量计费**（因为使用量小）
4. 点击"确定"创建

### 1.3 获取访问域名

创建完成后，腾讯云会自动分配一个临时域名，格式如：
```
https://xxxx-xxx-xxx.cdn.staticfile.tech/
```
记下这个域名，稍后要分享给团队。

---

## 步骤2：本地构建项目（3分钟）

打开终端，进入项目目录：

```bash
# 进入项目目录
cd /path/to/chapter-list-redesign

# 安装依赖（如果之前没有安装）
npm install

# 构建项目
npm run build

# 构建完成后，查看dist文件夹
ls dist/
```

**检查结果：**
- ✅ 应该看到 `dist/` 文件夹
- ✅ 文件夹内有 `index.html` 以及 `assets/` 子文件夹

---

## 步骤3：上传文件到腾讯云（5分钟）

### 3.1 进入文件管理

1. 登录腾讯云控制台
2. 进入"静态网站托管"
3. 找到刚才创建的网站，点击进入
4. 点击"文件管理"标签

### 3.2 上传文件

**方法一：拖拽上传（推荐，最简单）**
1. 打开本地 `dist/` 文件夹（Finder/文件管理器中）
2. 选中所有文件（Ctrl+A 或 Cmd+A）
3. 拖拽到腾讯云控制台的上传区域
4. 等待上传完成

**方法二：按钮上传**
1. 点击"上传文件"按钮
2. 选择本地 `dist/` 文件夹
3. 确认上传

### 3.3 配置根目录文件

如果这是第一次上传，需要设置主页文件：
1. 进入"基础配置"
2. 设置"默认根目录文件"为 `index.html`
3. 保存配置

---

## 步骤4：发布网站（1分钟）

1. 回到"文件管理"
2. 点击页面顶部的"发布"按钮
3. 在弹窗中确认
4. 等待发布完成（通常1-2分钟）

**发布完成后：**
- 您的网站已上线！
- 访问腾讯云提供的域名即可查看原型

1. 进入"域名管理"
2. 点击"绑定域名"
3. 输入你的域名
4. 按指引添加DNS记录

## 常见操作

### 更新原型

当你修改了代码后，只需：

```bash
# 1. 重新构建
npm run build

# 2. 上传新文件
# 用相同流程重复步骤3、4

# 3. 刷新访问
# 团队在浏览器中Ctrl+R（或Cmd+Shift+R硬刷新）查看新版本
```

### 清理旧文件

如果上传错了文件或想清理空间：
1. 进入"文件管理"
2. 选中要删除的文件
3. 点击"删除"

### 查看访问统计

1. 进入"统计分析"
2. 可以看到：
   - 访问次数
   - 带宽使用量
   - 流量消耗
3. 根据实际使用量评估成本

## 故障排查

### 问题：上传后访问显示404

**解决：**
1. 检查是否点击了"发布"按钮
2. 检查是否设置了 `index.html` 为根目录文件
3. 等待1-2分钟让CDN同步

### 问题：页面加载很慢

**解决：**
1. 刷新浏览器缓存（Ctrl+Shift+Del）
2. 检查文件大小（dist文件夹大小不应超过10MB）
3. 联系腾讯云技术支持

### 问题：SPA路由不工作

**解决：**
1. 进入"高级配置"
2. 启用"单页应用SPA"
3. 设置"错误页面"为 `index.html`

### 问题：跨域请求失败

**解决：**
如果您的应用需要调用外部API：
1. 进入"跨域配置"
2. 添加允许的源地址
3. 保存配置
