## 第一步：创建存储桶（Bucket）- 3分钟

### 1.1 进入 COS 创建页面

1. 登录 [腾讯云控制台](https://console.cloud.tencent.com/cos)
2. 在左侧菜单找到"对象存储"或直接进入 COS
3. 点击蓝色的"创建存储桶"按钮

### 1.2 填写存储桶信息

填写表单字段：

| 字段 | 填写值 | 说明 |
|------|-------|------|
| **存储桶名称** | `chapter-list-redesign` | 自定义名称（只能小写字母、数字、连接符） |
| **所属地域** | `广州` 或 `北京` | 建议选择离团队最近的地区 |
| **存储桶访问权限** | `公有读` | 让团队可以访问（重要！） |
| **服务端加密** | 不勾选 | 保持默认 |

**关键设置：**
- ✅ 必须选择"公有读"，否则团队无法访问
- ✅ 存储桶名称必须全局唯一（如果提示重名，可在后面加日期）

### 1.3 创建存储桶

点击"创建"按钮，等待 1-2 秒创建完成。

---

## 第二步：配置静态网站托管 - 3分钟

创建完成后，进入存储桶设置。

### 2.1 进入基础配置

1. 点击刚创建的存储桶名称进入存储桶详情页
2. 左侧菜单找到"基础配置"
3. 向下滚动找到"静态网站托管"部分

### 2.2 启用静态网站托管

找到"静态网站托管"配置项：

| 设置项 | 配置值 | 说明 |
|--------|--------|------|
| **状态** | 启用 | 勾选启用 |
| **索引文档** | `index.html` | SPA应用首页 |
| **错误文档** | `index.html` | 关键！所有404都返回index.html，让Vue路由工作 |
| **重定向协议** | HTTPS | 可选，建议启用 |

**保存配置**

点击保存后，系统会生成一个"静态网站访问域名"，记下它：
```
格式如：https://chapter-list-redesign-xxxx.cos-website.ap-guangzhou.myqcloud.com
```

---

## 第三步：配置 CDN 加速 - 2分钟

### 3.1 进入域名与传输管理

1. 在存储桶设置中，左侧菜单找到"域名与传输管理"
2. 点击"域名与传输管理" → "基础配置"

### 3.2 启用 CDN 加速

找到"CDN加速"部分：

| 设置项 | 配置值 | 说明 |
|--------|--------|------|
| **CDN 加速** | 启用 | 勾选启用 |
| **加速域名** | 自动分配 | 腾讯云自动生成，格式如：`xxx.file.myqcloud.com` |

**记下 CDN 加速域名** - 这是你要分享给团队的链接！

### 3.3 CORS 跨域配置

找到"CORS（跨域资源共享）"部分：

1. 点击"设置"
2. 点击"添加规则"
3. 填写规则：

| 字段 | 值 |
|------|-----|
| 来源(Origin) | `*` |
| 允许HTTP方法 | `GET, HEAD, PUT, POST, DELETE, OPTIONS` |
| 允许Header | `*` |
| 暴露Header | `ETag, x-cos-request-id` |

**保存设置**

## 第四步：本地构建项目 - 3分钟

打开终端，进入你的项目目录：

```bash
# 进入项目目录
cd /path/to/chapter-list-redesign

# 构建项目（生成 dist 文件夹）
npm run build

# 验证构建成功
ls dist/
# 应该看到 index.html 和 assets/ 文件夹
```

**检查构建结果：**
- ✅ `dist/index.html` 存在
- ✅ `dist/assets/` 文件夹存在
- ✅ 总大小不超过 50GB（你的包容量）

### 方法一：使用腾讯云控制台拖拽上传（推荐）

**文件上传检查清单：**
- [ ] index.html 在根目录
- [ ] assets/ 文件夹在根目录
- [ ] 其他静态资源文件都已上传

### 方法二：使用 COSBrowser（官方工具，更方便）

如果拖拽上传不稳定，可以使用 COSBrowser：

1. 下载 [COSBrowser](https://cloud.tencent.com/document/product/436/11366)
2. 登录腾讯云账号
3. 选择你的存储桶
4. 拖拽 dist 文件夹上传

### 验证上传成功

上传完成后，检查文件列表：
- ✅ 应该看到 `index.html`
- ✅ 应该看到 `assets/` 文件夹

## 常见问题解决

### 问题1：上传后访问显示404

**解决步骤：**
1. 确认已启用"静态网站托管"
2. 确认"错误文档"设置为 `index.html`
3. 等待 1-2 分钟让配置生效
4. 清空浏览器缓存重新访问

### 问题2：SPA 路由不工作（访问子路由时404）

**解决步骤：**
1. 检查"错误文档"是否设置为 `index.html`
2. 这个设置至关重要，所有 404 必须返回 index.html
3. 保存后等待配置同步

### 问题3：CDN 域名访问很慢

**解决步骤：**
1. 确认已启用"CDN加速"
2. 等待 5-10 分钟让 CDN 节点同步
3. 尝试硬刷新浏览器（Ctrl+Shift+Delete）
4. 如持续缓慢，在 CDN 加速配置中调整缓存规则

### 问题4：跨域请求失败

**解决步骤：**
1. 检查是否配置了 CORS
2. CORS 规则应该允许 GET、HEAD、OPTIONS
3. 如调用外部 API，需在 API 服务端配置跨域

### 问题5：图片或资源加载失败

**解决步骤：**
1. 检查 assets 文件夹是否已上传
2. 在浏览器开发者工具（F12）检查网络请求
3. 确认资源路径正确（相对路径而非绝对路径）

## 安全性和权限

### 确保访问控制

1. 存储桶权限设置为"公有读"
2. 建议不要在 COS 中存储敏感数据
3. 如需限制访问，可：
   - 配置 IP 白名单
   - 配置防盗链（Referer）
   - 使用临时链接

### 如何生成临时访问链接

如果需要限制访问时间：

1. 进入"文件列表"
2. 右键点击 index.html
3. 选择"生成临时链接"
4. 设置有效期（如24小时、7天）
5. 复制链接分享
