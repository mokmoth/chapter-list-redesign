🚀 部署步骤（共20分钟）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【步骤1】创建存储桶 (3分钟)
─────────────────────────────────────────────────────────────────────────────────
□ 打开腾讯云 COS 控制台：https://console.cloud.tencent.com/cos
□ 点击"创建存储桶"蓝色按钮
□ 填写表单：
   • 存储桶名称：chapter-list-redesign
   • 地域：广州 或 北京
   • 访问权限：公有读 ⚠️ 必须选择公有读！
□ 点击"创建"按钮
□ 等待 1-2 秒，存储桶创建完成


【步骤2】配置静态网站托管 (3分钟)
─────────────────────────────────────────────────────────────────────────────────
□ 进入存储桶详情页
□ 左侧菜单 → "基础配置"
□ 向下滚动找到"静态网站托管"部分
□ 启用静态网站托管：
   • 状态：勾选"启用"
   • 索引文档：index.html
   • 错误文档：index.html ⚠️ 关键！必须设为 index.html（SPA路由需要）
   • 重定向协议：HTTPS（可选）
□ 点击"保存"
□ 记下生成的"静态网站访问域名"


【步骤3】启用 CDN 加速 (2分钟)
─────────────────────────────────────────────────────────────────────────────────
□ 左侧菜单 → "域名与传输管理"
□ 找到"CDN加速"部分
□ 勾选启用 CDN 加速
□ 腾讯云自动分配加速域名（格式如：xxx.file.myqcloud.com）
□ 记下这个 CDN 加速域名 ✅ 这是最终的分享链接
□ 向下找到"CORS（跨域资源共享）"
□ 点击"设置" → "添加规则"
□ 填写 CORS 规则：
   • 来源(Origin)：*
   • 允许HTTP方法：GET, HEAD, PUT, POST, DELETE, OPTIONS
   • 允许Header：*
   • 暴露Header：ETag, x-cos-request-id
□ 点击"保存"


【步骤4】本地构建项目 (3分钟)
─────────────────────────────────────────────────────────────────────────────────
□ 打开终端
□ 进入项目目录：cd /path/to/chapter-list-redesign
□ 运行构建命令：npm run build
□ 验证构建成功：
   • ls dist/ 应该看到 index.html
   • ls dist/assets/ 应该看到资源文件
□ 构建完成！


【步骤5】上传文件到 COS (5分钟)
─────────────────────────────────────────────────────────────────────────────────
□ 进入 COS 存储桶 → "文件列表"
□ 方法一：拖拽上传（推荐）
   • 打开本地 dist/ 文件夹
   • 拖拽所有文件到 COS 控制台
   • 等待上传完成

   方法二：使用 COSBrowser（如拖拽不稳定）
   • 下载 COSBrowser 工具
   • 登录腾讯云
   • 拖拽上传 dist/ 文件

□ 上传完成后检查：
   • 应该看到 index.html 在根目录
   • 应该看到 assets/ 文件夹


【步骤6】获取分享链接 (2分钟)
─────────────────────────────────────────────────────────────────────────────────
□ 进入"域名与传输管理"
□ 找到"CDN加速"部分
□ 复制"加速域名"（格式如：https://chapter-list-redesign-xxx.file.myqcloud.com）
□ 这就是你要分享给团队的最终链接！


【步骤7】测试访问 (2分钟)
─────────────────────────────────────────────────────────────────────────────────
□ 打开你的 CDN 链接
□ 检查页面是否正常显示
□ 测试交互功能是否工作
□ 测试路由：刷新页面应该不会 404
□ 用手机浏览器测试响应式设计


【步骤8】分享给团队 (1分钟)
─────────────────────────────────────────────────────────────────────────────────
□ 复制你的 CDN 链接
□ 发送到团队微信/钉钉/Slack
□ 附加说明文本：

   ═══════════════════════════════════════════════
   【原型分享】我的 Vue 原型已上线

   访问链接：[你的 CDN 链接]

   说明：
   • 设计师：查看所有交互效果
   • 工程师：用 F12 查看源代码
   • 产品：分享给利益相关方演示

   用浏览器直接打开即可，支持所有设备
   ═══════════════════════════════════════════════

□ 完成！

❌ 常见错误（避免这些！）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ 错误1：访问权限设为"私有"
   ✅ 应该设为"公有读"

❌ 错误2：错误文档没有设为 index.html
   ✅ SPA 路由不工作的主要原因！必须设为 index.html

❌ 错误3：没有配置 CORS
   ✅ 前端调用 API 时会出现跨域错误

❌ 错误4：上传了文件但没有点击"发布"
   ✅ 腾讯云 COS 无需额外发布，上传即可访问

❌ 错误5：只上传了 assets 文件夹，忘了上传 index.html
   ✅ 必须上传根目录的 index.html


🔧 故障排查
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

问题：访问链接显示 404
解决：
  1. 检查是否启用了"静态网站托管"
  2. 检查"错误文档"是否设为 index.html
  3. 检查 index.html 是否上传到根目录
  4. 等待 1-2 分钟让配置同步

问题：SPA 路由不工作
解决：
  1. 确认"错误文档"设为 index.html
  2. 这是最常见原因！

问题：资源加载失败（404、跨域错误）
解决：
  1. 检查 assets/ 文件夹是否上传
  2. 检查是否配置了 CORS
  3. 用 F12 开发者工具查看具体错误

问题：访问速度很慢
解决：
  1. 确认 CDN 加速已启用
  2. 等待 5-10 分钟让 CDN 节点同步
  3. Ctrl+Shift+R 硬刷新缓存
