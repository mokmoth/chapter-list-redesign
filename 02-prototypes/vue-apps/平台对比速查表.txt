🚀 快速开始 (30分钟)

1️⃣  开通腾讯云静态托管 (3分钟)
   └─ 登录腾讯云 → 搜索"静态网站托管" → 创建网站

2️⃣  本地构建项目 (3分钟)
   └─ npm run build (生成 dist/ 文件夹)

3️⃣  上传文件 (5分钟)
   └─ 拖拽 dist/ 文件到腾讯云控制台

4️⃣  发布网站 (1分钟)
   └─ 点击"发布"按钮

5️⃣  分享链接 (2分钟)
   └─ 复制域名分享给团队

总耗时：30分钟
总费用：¥0-50

❓ 常见问题速答

Q: 部署后能更新原型吗?
A: 可以，每次更新只需重新 npm run build + 重新上传 dist/ + 发布，共5分钟

Q: 团队能看到我的源代码吗?
A: 不能，他们只能访问编译后的代码

Q: 可以自定义域名吗?
A: 可以，腾讯云提供免费二级域名，也支持绑定自己的域名

Q: 有访问限制吗?
A: 没有，按实际使用按量计费

Q: SPA路由能正常工作吗?
A: 完全支持，默认配置即可

Q: 支持HTTPS吗?
A: 支持，免费HTTPS
